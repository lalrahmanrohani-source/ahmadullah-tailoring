AHMADULLAH TAILORING - OFFLINE PWA

Upload ALL files in this folder to the ROOT of your GitHub Pages repository. Keep the names unchanged:
- index.html
- sw.js
- manifest.json
- icon-192.png
- icon-512.png

Then open the GitHub Pages HTTPS address once while connected to the internet. Wait until the page finishes loading. In Chrome, open the menu (three dots) and choose Install app or Add to Home screen.

After the first successful online visit and caching, the app shell can open offline from its home-screen icon.

IMPORTANT: Records are stored locally on each phone/browser. Sending the link or installing the app on another phone does NOT synchronize records between phones. Each person has their own separate records. Internet-dependent features such as WhatsApp sharing still need internet. Do not clear Chrome site data or uninstall the app if you need to preserve locally stored records; keep backups.
